UrbanOps, is a python package that allows for unified way to connect, visualize and use street data. You can download streets, curb segments, event points, polygons, design interventions, transit stops, and accessibility zones and integrate them  and model walking, driving, or biking networks and integrate them with operational data to assess and visualize hotspots, accessibility performance and design interventions with a single batch of code. The goal is to create a computational framework integrating data, operations, and design through a common set of abstractions, algorithms, and visualizations.
