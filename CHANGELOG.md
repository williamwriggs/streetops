# Changelog

All notable changes to StreetOps will be documented in this file.

The project uses semantic versioning while it develops toward a stable public API. Versions below 1.0 may include changes to proposed interfaces as the research framework is implemented and validated.

## [0.1.0] — 2026-09-07

### Initial Research Release

- Published the initial StreetOps framework specification.
- Defined the six-stage workflow: Acquire, Integrate, Diagnose, Translate, Generate Scenarios, and Evaluate.
- Defined the proposed `OpsGraph` technical abstraction.
- Documented the intended compositional architecture and interoperability with the open geospatial Python ecosystem.
- Specified initial abstractions for study areas, operational events, time periods, public priorities, diagnoses, translation rules, interventions, scenarios, and evaluation.
- Documented the proposed Operations Rose and associated geographic visualization system.
- Published the staged implementation roadmap and Hayes Valley reference-workflow plan.
- Added citation metadata and GPL-3.0 licensing.

### Status note

Version 0.1.0 is a research-preview release. It establishes the conceptual framework, architecture, public interface targets, and implementation roadmap. It should not be interpreted as a completed or stable Python package.
